## 背景

我们正在开发一个试卷智能分析系统。核心功能之一是对每道题评估难度（2-10分制）。

### v3 模型当前设计

6 个评分维度（全部由 LLM 一次提取）：
- working_memory (1-5): 工作记忆负荷
- reasoning_steps (1-10): 推理链长度
- chain_coupling (1-3): 推理耦合度（1=独立, 2=部分依赖, 3=全链依赖）
- trap_density (1-3): 陷阱密度
- novelty (1-3): 熟悉度缺口
- knowledge_breadth (1-3): 知识整合跨度

评分公式: effective_steps = steps × coupling_multiplier(1.0/1.3/1.6)
各维度查表映射到 0-1 后加权求和:
working_memory: 0.28, effective_steps: 0.28, trap_density: 0.18, novelty: 0.14, knowledge_breadth: 0.12

bloom (1-6) 不参与评分，仅用于教学报告。

### 核心问题

**大题（非选择题，12-14分，3-5个小问）和选择题（2分）共用同一套 LLM 特征提取 + 规则评分，导致大题难度被系统性低估。**

具体表现：LLM 对大题的 chain_coupling 和 reasoning_steps 判断偏保守——它把各小问当成"部分独立"，但实际上很多大题的小问之间存在强链式依赖。改 prompt 是钝器，会影响所有题目。

### Q21 深度分析

Q21（14分）要求学生：
(1) 回答番茄红素合成相关基础知识
(2) 分析GFP-PSY融合蛋白为何在细胞质基质而非有色体（N端转运肽被GFP遮挡）→ 提出改造方案（PSY-GFP，把GFP放C端）
(3) 根据载体构建设计引物 + 判断正反插入的PCR条带大小

LLM 给的 chain_coupling=2，但实际上：
- 不知道第2问的N端遮挡原因 → 就不知道改造方向 → 就不知道引物设计 → 就不知道PCR产物大小
- 这是典型的全链依赖（coupling=3）

LLM 给的 steps=6，但实际至少 8-9 步（判定位失败→分析遮挡→重设融合→改载体→设计引物→判断正插→计算正插条带→判断反插→计算反插条带）

LLM 给的 novelty=2，但 In-Fusion 克隆技术在高中教材中完全没有。

## 需要你回答的问题

1. **整体评分是否合理？** 看 21 题的数据分布，选择题 4.2-8.8，非选择题 7.6-10.0。这个分布是否符合你对高中生物试卷的直觉？哪些题的评分明显偏差？

2. **"一次 LLM 调用评整道大题"的架构是否合理？** 选择题各选项独立判断（coupling=1）天然合理，但大题多小问的评估是否需要拆分？

3. **如果拆分，怎么聚合？** 我的初步想法是：
   - 选择题（≤4分）：现有流程不变
   - 大题（≥8分）：LLM 按小问分别输出特征 → 各小问独立评分 → 聚合公式
   - 聚合方案 A：最难小问×0.6 + 平均×0.4 + 小问间耦合加分
   - 聚合方案 B：加权平均（按分值）+ 耦合惩罚
   - 聚合方案 C：取整体评估和拆分评估的较高值（max）
   你推荐哪个？或有更好的方案？

4. **成本考量**：拆分评估意味着大题需要 N 次 LLM 调用（每小问一次），成本增加。是否值得？有没有折中方案？

5. **任何其他你认为我们遗漏的问题。**

请基于实际数据给出具体、可操作的建议。不要泛泛而谈。
