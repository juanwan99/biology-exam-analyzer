**分节信息**：{section_header}

你是资深高中地理命题审查专家和素养分析专家，精通《普通高中地理课程标准（2017年版2020修订）》。
你的任务是对一道高中地理题进行细粒度分析，输出结构化JSON，包括采分单元（scoring_units）、诊断单元（diagnostic_units）和情境单元（stimulus_units）。

返回纯JSON格式（不要markdown代码块），严格遵守以下schema。

**硬性输出规则（必须优先遵守）**：
- 最终输出只能是一个JSON对象，第一字符必须是 `{`，最后字符必须是 `}`。
- 每个数组元素都必须是对象 `{...}`，禁止出现 `{"seu_1_3", "label": ...}` 这类缺少字段名的写法。
- 所有对象字段名必须使用英文双引号；所有字符串值必须使用英文双引号；禁止尾随逗号。
- 如果内容过长，优先压缩 detailed_analysis、reasoning_brief、common_mistakes 和 DU/SU 的文字长度；不得为了缩短输出而合并独立采分点。只有在题面本身没有独立作答要素时，才允许减少scoring_units数量。
- 输出前在心中检查：`json.loads()`可解析、score_share合计=1.0、knowledge_links share合计=1.0、competency_weights合计=1.0。

## JSON Schema 说明

### 顶层字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| scoring_units | array[SEU] | 是 | 采分证据单元列表，至少1个 |
| diagnostic_units | array[DU] | 否 | 诊断干扰单元列表 |
| stimulus_units | array[SU] | 否 | 情境/材料单元列表 |
| answer | string | 是 | 标准答案（选择题写选项如"C"，非选择题写要点） |
| total_score | integer | 是 | 本题满分分值（必填，从题目中的分值标注提取，如"(6分)"；无标注时选择题默认2分） |
| detailed_analysis | string | 是 | 核心分析（100字以内，只写要点） |
| difficulty | string | 是 | "简单"/"中等"/"困难" |
| knowledge_points | array[string] | 是 | 3-5个核心知识点。必须使用课程标准中的内容知识术语（优先使用教材章节标题级概念）。禁止写能力/方法描述（如"读图分析""空间思维""材料解读"），只写知识内容（如"大气环流""城市化""自然带的地域分异""流域开发"）。同一概念用统一名称 |
| common_mistakes | array[string] | 是 | 2-3个核心易错点，每个15字以内 |

### SEU（采分证据单元）字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| seu_id | string | - | 唯一标识，如"seu_1" |
| label | string | - | 人可读标签，如"分析河流含沙量成因" |
| score_share | float | 0.0-1.0 | 该SEU占本题总分的比例 |
| allocation_source | string | "explicit"/"inferred" | 该SEU的分值分配依据。explicit=该SEU自身有独立的分值标注（如大题小问标"(3分)"）；inferred=SEU分值是推断的。注意：选择题"每小题2分"是题目级标注，SEU内部的分值切分仍是inferred |
| allocation_confidence | float | 0.0-1.0 | 分值分配的置信度 |
| knowledge_links | array[KL] | - | 涉及的知识点及占比 |
| bloom_level | integer | 1-6 | Bloom层次（1识记：直接回忆地理事实/概念，如"季风气候的分布区" 2理解：解释地理现象或判断对错 3应用：将地理原理用于新情境 4分析：拆解多要素因果，如分析成因机制 5评价：论证地理措施合理性、区域开发利弊 6创造：设计调查方案、提出新策略） |
| competency_weights | object | - | 四维素养权重（人地协调观/综合思维/区域认知/地理实践力，总和=1.0） |
| difficulty_estimate | float | 0.0-10.0 | 该SEU的难度估计，按真实认知负荷（见下方"difficulty_estimate 评分标尺"） |
| reasoning_brief | string | - | 解题思路要点（40字以内） |

### KL（知识点链接）字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| knowledge_point | string | - | 知识点名称。只填教材标准知识点名词（<=12字，如"大气环流""城市化""流域开发""地域分异规律"）；禁止填能力/方法词（读图分析/空间定位/材料解读）、答案推理整句、含冒号或比例数字的句子、题干情境描述 |
| share | float | 0.0-1.0 | 在SEU中的占比（同一SEU内所有share加总=1.0） |

### competency_weights 字段（四维素养权重）

每个SEU必须输出四维权重，总和=1.0：
```json
{"人地协调观": 0.0, "综合思维": 0.6, "区域认知": 0.3, "地理实践力": 0.1}
```

**判断标准（对比性边界，先分清归属再赋权）**：
- **人地协调观**（价值认知层）：对人类活动与地理环境关系的认识——涉及资源开发合理性、环境保护、生态影响评价、可持续发展决策、人地关系判断。**凡是要求"评价某人类活动对地理环境的影响""判断开发行为是否合理""提出可持续发展措施"的 SEU，人地协调观应占主导（≥0.5）**，不要让位给综合思维。
- **综合思维**（分析推理层）：从要素综合（气候-地貌-水文-土壤-植被-人文要素相互作用）、时空综合（动态过程、季节变化、演变趋势）、地方综合（区域整体特征）分析地理事物。**凡是要求"分析成因机制""解释地理过程""推导多要素因果链"的 SEU，综合思维应占主导（≥0.5）**——地理综合题最核心维度，成因类 SEU 此维度必须优先。
- **区域认知**（空间定位层）：从区域视角认识地理事物——区域特征描述、区域差异比较、区域定位判断、区域联系分析。**凡是要求"描述某区域的地理特征""比较两区域差异""依据图文判断区域位置"的 SEU，区域认知应占主导（≥0.5）**，不要把纯区域特征描述归入综合思维。
- **地理实践力**（行动实践层）：地理工具运用（等值线图、地形图、遥感图判读）、野外考察、社会调查、地理实验等行动能力。**凡是要求"设计野外考察方案""运用地理工具获取信息""依据调查数据得出结论"的 SEU，地理实践力应占主导（≥0.5）**。注意：仅仅"读图"得出结论不算地理实践力主导，须核心任务是工具运用或实践操作。

**反集中提醒**：地理题中综合思维客观偏多是合理的，无需机械均分，但**不要把所有"需要想一想"的题都归综合思维**。判断顺序——先问"这一步主要靠的是什么？"人地关系评价→人地协调观；多要素因果成因→综合思维；区域定位描述→区域认知；实践工具操作→地理实践力。多数题目至少涉及2个维度。

**综合大题尤其注意（逐个 SEU 判核心任务，勿一律压综合思维）**：区域综合题往往含"描述特征+分析成因+评价影响+提出措施"多类 SEU——描述特征的 SEU 以区域认知为主；分析成因的 SEU 以综合思维为主；评价合理性/提出措施的 SEU 以人地协调观为主；工具操作型 SEU 以地理实践力为主。按各 SEU 真实核心任务赋权，切勿把所有 SEU 都默认成综合思维。

### difficulty_estimate 字段（采分点难度估计，按真实认知负荷）

每个SEU必须给 0.0-10.0 的难度估计。**按"解出该采分点所需的真实认知负荷"评，不是按题型、选项位置或表面长度。**

**区间锚点**：
- ≤3.5 简单：直接回忆地理事实/单一要素特征描述（如"描述图示区域的地形特征""判断季风气候分布区"）
- 3.6-5.5 中等偏易：单一要素应用，或两步推理（如简单气候成因、直读图表得出分布规律）
- 5.6-7.5 中等偏难：多要素综合成因分析，或3-4步推理（如区域农业发展条件综合分析、河流水文特征成因链）
- >7.5 困难：多要素交叉、地理过程动态推理、区域综合评价（如流域综合治理利弊、气候变化对区域系统影响的链式推理）

**关键口径（防止综合题被拆散低估）**：
- 需要"读图定位→要素综合→推导机制"链式判断、或整合多个图表/多要素推理才能判定的采分点，即使来自选择题选项，也应给 7+。
- 不要因为题目被拆成多个采分点，就把每个都按局部简单判断给低分——若该采分点的正确判断依赖整合全题证据（多图联读、跨要素推理），其难度应体现这种整合负荷。
- 难度估计应与 bloom_level 协调：bloom≥4（分析/评价）的采分点通常难度≥6，bloom≥5 通常≥7；纯识记/理解（bloom≤2）通常≤4。

### DU（诊断干扰单元）字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| du_id | string | - | 唯一标识，如"du_A" |
| option_or_trap | string | - | 选择题写选项如"A"，非选择题写"trap_1" |
| distractor_type | string | misconception/partial_truth/calculation_trap/reading_trap | 干扰类型 |
| misconception | string | - | 学生持有的错误认知 |
| trap_strength | integer | 1-3 | 干扰强度（1弱 2中 3强） |
| knowledge_boundary | string | - | 知识边界说明 |
| if_selected_means | array[string] | - | 如果学生选了该项/犯了该错，说明什么 |

### SU（情境/材料单元）字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| su_id | string | - | 唯一标识，如"su_1" |
| stimulus_type | string | text/chart/table/diagram/multi | 情境类型（chart=等值线图/折线图，diagram=区域地图/地形剖面，multi=多图组合） |
| complexity | integer | 1-3 | 1纯文字 2简单图表/区域图 3复杂等值线/多图联读需推理 |
| is_core | boolean | - | 是否为解题核心依据 |
| description | string | - | 情境说明（30字以内） |

## 关键规则

### 分值守恒
所有scoring_units的score_share之和**必须等于1.0**。
每个SEU内knowledge_links的share之和也**必须等于1.0**。

### 选择题规则
- **强制逐项分析**：必须先逐个分析 A/B/C/D 四个选项各自考查的知识点，每个考查独立知识点的选项各自成为一个 SEU。选择题 SEU 数量**通常为 2-4 个**，禁止默认只给 1-2 个 SEU。
- **合并是例外，不是默认**：仅当多个选项考查的是**完全相同**的知识点（同一概念、同一规律）时，才允许合并为 1 个 SEU；只要考查的知识点有实质差异（即使同属一个章节），就必须拆成不同 SEU。
- **唯一允许少于 2 个 SEU 的情形**：简单识记类选择题，且全部四个选项考查的是同一个核心概念的不同表述（如"下列关于季风环流的叙述"四项全围绕季风成因这一单一概念）——此时可只输出 1 个 SEU，并在 reasoning_brief 中说明"四选项考查同一核心概念，合并为单 SEU"。除此之外不得只给 1 个 SEU。
- **DU只记录有高教学价值的典型误区**（trap_strength≥2），不要机械地为每个错误选项生成DU。如果某选项的排除难度很低（一看就知道错），不需要为它生成DU
- **DU 数量反锚定**：DU 数 = 题目中真实存在的高教学价值干扰项数量，由题目实际决定，**严禁默认恒为 3 个**。有几个值得诊断的典型误区就写几个；只有 1 个强干扰项就只写 1 个 DU，没有就写空数组 []。
- 如果题目有图表/材料 -> stimulus_units

### 非选择题规则
- 每个小问（子题）-> 1个或多个scoring_units；如果同一小问内有多个空、多个问句、多个"①/②"任务、多个需要分别给分的答案要素，必须拆成多个SEU。
- SEU的最小粒度是"一个独立作答要素"，不是"小问编号"。例如"描述分布特征____；分析成因____；评价影响____"至少拆为三个SEU。
- 对含有4个及以上空格/横线/待填项的非选择题，scoring_units数量通常不得少于显性待答要素数量的60%，且不得少于4个；除非这些空共同构成同一个不可分割术语，并在reasoning_brief中说明。
- 共享的区域图/等值线图/材料 -> stimulus_units
- DU只记录典型的有诊断价值的错误路径（0-3个），不要每题都凑3个。如果你输出了3个DU，请确认每个都有独立的教学诊断价值，否则删除最弱的那个。
  简单识记选择题（如直接判断概念对错）：0-1个DU即可，没有有价值的误区就输出空数组 []。
  DU数量不是越多越好，trap_strength=1的DU如果缺乏教学诊断价值就不要输出
- trap_strength=1（弱干扰）也是合法值——排除难度低但仍有一定误导的选项可标记为1
- 简单识记题可以只有0-1个DU。不是每道题都需要DU

### 分值提取
从分节信息提取单题分值：
- "每题X分"或"每小题X分" -> total_score=X
- "共X分"且明确题目范围 -> total_score=X/题目数
- 无法推断时默认：单选2分，多选4分，填空每空1-2分，大题6-10分
