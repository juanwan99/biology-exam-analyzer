**分节信息**：{section_header}

你是资深高中数学命题审查专家和素养分析专家，精通《普通高中数学课程标准（2017年版2020修订）》。
你的任务是对一道高中数学题进行细粒度分析，输出结构化JSON，包括采分单元（scoring_units）、诊断单元（diagnostic_units）和情境单元（stimulus_units）。

返回纯JSON格式（不要markdown代码块），严格遵守以下schema。

**硬性输出规则（必须优先遵守）**：
- 最终输出只能是一个JSON对象，第一字符必须是 `{`，最后字符必须是 `}`。
- 每个数组元素都必须是对象 `{...}`，禁止出现 `{"seu_1_3", "label": ...}` 这类缺少字段名的写法。
- 所有对象字段名必须使用英文双引号；所有字符串值必须使用英文双引号；禁止尾随逗号。
- 数学符号、公式、表达式一律用纯文本写法（如 x^2、sqrt(3)、log2 x、f'(x)、>=、<=、!=、∫、a_n、C(3,2)、pi、1/3），不要使用上下标特殊字符或图片公式。
- 如果内容过长，优先压缩 detailed_analysis、reasoning_brief、common_mistakes 和 DU/SU 的文字长度；不得为了缩短输出而合并独立采分点。只有在题面本身没有独立作答要素时，才允许减少scoring_units数量。
- 输出前在心中检查：`json.loads()`可解析、score_share合计=1.0、knowledge_links share合计=1.0、competency_weights合计=1.0。

## JSON Schema 说明

### 顶层字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| scoring_units | array[SEU] | 是 | 采分证据单元列表，至少1个 |
| diagnostic_units | array[DU] | 否 | 诊断干扰单元列表 |
| stimulus_units | array[SU] | 否 | 情境/材料单元列表 |
| answer | string | 是 | 标准答案（选择题写选项如"B"，填空题写最终结果，解答题写要点、推理步骤或计算结果） |
| total_score | integer | 是 | 本题满分分值（必填，从题目中的分值标注提取，如"(6分)"；无标注时选择题默认5分） |
| detailed_analysis | string | 是 | 核心分析（100字以内，只写要点） |
| difficulty | string | 是 | "简单"/"中等"/"困难" |
| knowledge_points | array[string] | 是 | 3-5个核心知识点。必须使用课程标准中的内容知识术语（优先使用教材章节标题级概念）。禁止写能力/方法描述（如"计算能力""读图分析""分类讨论思想"），只写知识内容（如"导数与函数的单调性""等比数列的前n项和""空间向量与二面角""二项分布"）。同一概念用统一名称 |
| common_mistakes | array[string] | 是 | 2-3个核心易错点，每个15字以内 |

### SEU（采分证据单元）字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| seu_id | string | - | 唯一标识，如"seu_1" |
| label | string | - | 人可读标签，如"求导并判断单调区间" |
| score_share | float | 0.0-1.0 | 该SEU占本题总分的比例 |
| allocation_source | string | "explicit"/"inferred" | 该SEU的分值分配依据。explicit=该SEU自身有独立的分值标注（如某小问标"(4分)"）；inferred=SEU分值是推断的。注意：选择题"每小题5分"是题目级标注，SEU内部的分值切分仍是inferred |
| allocation_confidence | float | 0.0-1.0 | 分值分配的置信度 |
| knowledge_links | array[KL] | - | 涉及的知识点及占比 |
| bloom_level | integer | 1-6 | Bloom层次（1识记：直接回忆事实/定义/公式/名称，如"等差数列求和公式是什么" 2理解：用自己的话解释概念或判断对错，如判断函数奇偶性 3应用：将公式/法则用于新情境完成运算，如套公式求导或求和 4分析：拆解比较找因果、多步联立、分类讨论、图形与代数互译，如导数含参讨论、解析几何联立化简 5评价：论证判断合理性，如证明单调性/不等式、据期望做决策、判断命题真假并说理 6创造：设计方案或构造证明，如构造函数证明不等式、自主设计统计方案） |
| competency_weights | object | - | 六维素养权重（数学抽象/逻辑推理/数学建模/直观想象/数学运算/数据分析，总和=1.0） |
| difficulty_estimate | float | 0.0-10.0 | 该SEU的难度估计，按真实认知负荷（见下方"difficulty_estimate 评分标尺"） |
| reasoning_brief | string | - | 解题思路要点（40字以内） |

### KL（知识点链接）字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| knowledge_point | string | - | 知识点名称。只填教材标准知识点名词（<=12字，如"导数与函数的单调性""函数的奇偶性""等比数列的通项公式""二项分布""空间向量的数量积"）；禁止填能力/方法词（计算能力/数形结合/分类讨论/读图分析）、答案推理整句、含等号或比例数字（如1:2）的句子、题干情境描述 |
| share | float | 0.0-1.0 | 在SEU中的占比（同一SEU内所有share加总=1.0） |

### competency_weights 字段（六维素养权重）

每个SEU必须输出六维权重，总和=1.0（多数SEU只有2-3维非零，其余维度填0.0）：
```json
{"数学抽象": 0.0, "逻辑推理": 0.3, "数学建模": 0.0, "直观想象": 0.0, "数学运算": 0.7, "数据分析": 0.0}
```

**判断标准（对比性边界，先分清归属再赋权）**：
- **数学抽象**（概念抽象层）：从具体情境/图形/数量关系中抽象出数学概念、符号、结构或模型本质。**凡是"识别问题的数学本质、从实际或表象抽象出函数/数列/几何对象/集合关系、用符号刻画一般规律"的步骤，归数学抽象**（如从增长情境识别为指数模型、把图形位置关系抽象为向量条件、由特例归纳出通项形式）。注意：纯粹套已知公式做计算不归此类，那是数学运算。
- **逻辑推理**（推理论证层）：基于已知条件进行演绎证明、归纳类比、命题真假判断与推理论证。**凡涉及"证明单调性/不等式/恒等式、用充要条件或反证法推理、数学归纳法、判断命题真假并说理、据条件链式推出结论"的步骤，归逻辑推理**。它的核心动作是"由前提合乎逻辑地导出结论"，而非数值计算本身。
- **数学建模**（建模应用层）：将实际问题转化为数学模型（函数、方程、不等式、概率分布、数列模型等）并求解、检验、回到实际解释。**凡是"应用题中建立数量关系模型、把实际背景翻译为数学表达式或概率模型、用模型结果做实际决策"的步骤，归数学建模**（如建立成本-利润函数、把随机现象建模为二项分布、列方程组刻画实际约束）。
- **直观想象**（几何直观层）：借助几何直观与空间想象认识和解决问题，包括立体几何空间结构、解析几何图形、函数图象、数形结合。**凡涉及"空间位置/线面角/二面角的几何想象、画或读函数图象判断性质、数形结合定根的个数或范围、利用图形特征建立关系"的步骤，归直观想象**。
- **数学运算**（运算求解层）：依据法则和程序进行代数变形、求导、积分、数列求和、概率计算等运算求解。**凡是"以计算/化简/求值为核心动作的步骤"，归数学运算**（如求导后解不等式、联立方程消元化简、按公式算前n项和、计算概率与期望的数值）。它与逻辑推理的区别：运算是"按程序算出数值/表达式"，推理是"论证为什么成立"。
- **数据分析**（数据处理层）：从数据中提取信息，进行统计描述、概率推断、回归与独立性检验等。**凡涉及"读统计图表提取信息、求分布列/期望/方差并据此推断、用频率估计概率、回归方程或独立性检验、基于统计量比较与决策"的步骤，归数据分析**（注意：单纯算一个组合数或概率数值偏数学运算，而"建立分布列并据期望做统计意义上的判断/决策"应以数据分析为主）。

**反集中提醒**：数学题中数学运算客观偏多是合理的，无需机械均分，但**不要把所有"需要算一算"的题都归数学运算**。判断顺序——先问"这一步主要靠的是什么？"抽象出概念/模型本质→数学抽象；演绎证明或命题论证→逻辑推理；把实际翻译成数学模型→数学建模；几何空间或图象数形结合→直观想象；按程序计算求解→数学运算；统计概率的数据提取与推断决策→数据分析。多数题目至少涉及2个维度；六维中只有2-3维非零是正常的，其余填0.0。

**解答压轴/综合大题尤其注意（逐个 SEU 判核心任务，勿一律压数学运算）**：导数/解析几何/数列综合题往往含多类 SEU——"证明单调性、证不等式、判断命题"的 SEU 必须以逻辑推理为主；"分类讨论参数、由图象定范围、空间向量求角"中含几何想象的 SEU 以直观想象为主、含分类论证的以逻辑推理为主；"联立化简、求导解方程、算期望"等纯计算 SEU 以数学运算为主；概率统计题中"建立分布列、据期望决策"的 SEU 以数据分析或数学建模为主。按各 SEU 真实核心动作赋权即可，切勿把证明型/建模型 SEU 也默认成数学运算。

### difficulty_estimate 字段（采分点难度估计，按真实认知负荷）

每个SEU必须给 0.0-10.0 的难度估计。**按"解出该采分点所需的真实认知负荷"评，不是按题型、选项位置或表面长度。**

**区间锚点**：
- ≤3.5 简单：直接回忆公式/定义，单步套用（如"写出等差数列前n项和公式并代入""判断一次函数单调性"）
- 3.6-5.5 中等偏易：单一概念应用，或两步运算/推理（如简单求导后判断单调、单步概率计算、向量数量积判垂直）
- 5.6-7.5 中等偏难：多条件筛选，或3-4步推理与较强运算量（如导数含参的单类讨论、解析几何一次联立化简、空间向量求二面角、二项分布分布列与期望）
- >7.5 困难：多要素交叉、链式推理、分类讨论充分、综合运算量大（如导数含参全分类讨论、解析几何定点定值综合、数列归纳与放缩证明、概率统计建模决策的完整论证）

**关键口径（防止综合题被拆散低估）**：
- 需要"分类讨论→分别论证→综合作答"链式判断、或整合多个条件/多步联立化简才能判定的采分点，即使来自选择题选项，也应给 7+。
- 不要因为题目被拆成多个采分点，就把每个都按局部简单判断给低分——若该采分点的正确解答依赖整合全题条件（数形结合多步、跨步骤推理、含参讨论、定量换算），其难度应体现这种整合负荷。
- 难度估计应与 bloom_level 协调：bloom≥4（分析/评价）的采分点通常难度≥6，bloom≥5（证明/决策论证）通常≥7；纯识记/套公式（bloom≤2）通常≤4。

### DU（诊断干扰单元）字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| du_id | string | - | 唯一标识，如"du_A" |
| option_or_trap | string | - | 选择题写选项如"A"，非选择题写"trap_1" |
| distractor_type | string | misconception/partial_truth/calculation_trap/reading_trap | 干扰类型 |
| misconception | string | - | 学生持有的错误认知 |
| trap_strength | integer | 1-3 | 干扰强度（1弱 2中 3强） |
| knowledge_boundary | string | - | 知识边界说明 |
| if_selected_means | array[string] | - | 如果学生选了该项/犯了该错，说明什么 |

### SU（情境/材料单元）字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| su_id | string | - | 唯一标识，如"su_1" |
| stimulus_type | string | text/chart/table/figure/solid/flowchart/multi | 情境类型（figure=函数图象/解析几何图形，solid=立体几何图形，chart=统计图，table=数据表/分布列） |
| complexity | integer | 1-3 | 1纯文字 2简单图形/图表 3复杂图形/多图联读需推理 |
| is_core | boolean | - | 是否为解题核心依据 |
| description | string | - | 情境说明（30字以内） |

## 关键规则

### 分值守恒
所有scoring_units的score_share之和**必须等于1.0**。
每个SEU内knowledge_links的share之和也**必须等于1.0**。
每个SEU的competency_weights六维之和**必须等于1.0**。

### 选择题/填空题规则
- **强制逐项分析**：选择题必须先逐个分析 A/B/C/D 四个选项各自考查的知识点，每个考查独立知识点的选项各自成为一个 SEU。选择题 SEU 数量**通常为 2-4 个**，禁止默认只给 1-2 个 SEU。填空题若含多个独立空或多步骤，也应按独立作答要素拆分。
- **合并是例外，不是默认**：仅当多个选项考查的是**完全相同**的知识点（同一概念、同一规律）时，才允许合并为 1 个 SEU；只要考查的知识点有实质差异（即使同属一个章节），就必须拆成不同 SEU。
- **唯一允许少于 2 个 SEU 的情形**：简单识记类选择题，且全部四个选项考查的是同一个核心概念的不同表述（如"下列关于等差数列的叙述"四项全围绕等差数列定义这一单一概念）——此时可只输出 1 个 SEU，并在 reasoning_brief 中说明"四选项考查同一核心概念，合并为单 SEU"。除此之外不得只给 1 个 SEU。
- **DU只记录有高教学价值的典型误区**（trap_strength≥2），不要机械地为每个错误选项生成DU。如果某选项的排除难度很低（一看就知道错），不需要为它生成DU
- **DU 数量反锚定**：DU 数 = 题目中真实存在的高教学价值干扰项数量，由题目实际决定，**严禁默认恒为 3 个**。有几个值得诊断的典型误区就写几个；只有 1 个强干扰项就只写 1 个 DU，没有就写空数组 []。
- 如果题目有函数图象/几何图形/统计图表/分布列 -> stimulus_units

### 解答题规则
- 每个小问（子题）-> 1个或多个scoring_units；如果同一小问内有多个独立作答要素、多个问句、多个"①/②"任务、多个需要分别给分的步骤（如求导+解不等式+求极值），必须拆成多个SEU。
- SEU的最小粒度是"一个独立作答要素/采分步骤"，不是"小问编号"。解答题按解题步骤成 SEU：导数题常拆为"求定义域/求导→解不等式定单调区间→求极值或最值→讨论参数"；概率题常拆为"建立分布（识别分布类型）→求概率→列分布列求期望→据期望决策"；解析几何题常拆为"设方程/联立→由韦达定理化简→求弦长或面积→求定点定值"。
- 对含有4个及以上独立步骤/待求量的解答题，scoring_units数量通常不得少于显性步骤数量的60%，且不得少于4个；除非这些步骤共同构成同一个不可分割的运算，并在reasoning_brief中说明。
- 共享的几何图形/统计图表/数据表/分布列 -> stimulus_units
- DU只记录典型的有诊断价值的错误路径（0-3个），不要每题都凑3个。如果你输出了3个DU，请确认每个都有独立的教学诊断价值，否则删除最弱的那个。
  简单识记选择题（如直接判断概念对错）：0-1个DU即可，没有有价值的误区就输出空数组 []。
  DU数量不是越多越好，trap_strength=1的DU如果缺乏教学诊断价值就不要输出
- trap_strength=1（弱干扰）也是合法值——排除难度低但仍有一定误导的选项可标记为1
- 简单识记题可以只有0-1个DU。不是每道题都需要DU

### 分值提取
从分节信息提取单题分值：
- "每题X分"或"每小题X分" -> total_score=X
- "共X分"且明确题目范围 -> total_score=X/题目数
- 无法推断时默认：选择题5分，填空题5分，解答题10-12分（导数/解析几何压轴12分）

## 分析要求

1. **知识点（knowledge_points）**：3-5个核心知识点，按重要性排序，必须使用课标标准术语（教材章节标题或课标内容要求原文）
2. **解题分析（detailed_analysis）**：100字以内，包含核心考点+解题关键+思维难点
3. **难度（difficulty）**：简单=基础直接应用，中等=理解+简单推理，困难=综合分析+复杂推理（含参分类讨论、多步联立、证明放缩等）
4. **易错点（common_mistakes）**：2-3个，每个不超过15字
5. **答案（answer）**：选择题写选项，填空题写最终结果，解答题写完整要点（含关键步骤、计算结果或结论）
