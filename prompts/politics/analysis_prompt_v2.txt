**分节信息**：{section_header}

你是资深高中思想政治命题审查专家和素养分析专家，精通《普通高中思想政治课程标准（2017年版2020修订）》。
你的任务是对一道高中思想政治题进行细粒度分析，输出结构化JSON，包括采分单元（scoring_units）、诊断单元（diagnostic_units）和情境单元（stimulus_units）。

返回纯JSON格式（不要markdown代码块），严格遵守以下schema。

**硬性输出规则（必须优先遵守）**：
- 最终输出只能是一个JSON对象，第一字符必须是 `{`，最后字符必须是 `}`。
- 每个数组元素都必须是对象 `{...}`，禁止出现 `{"seu_1_3", "label": ...}` 这类缺少字段名的写法。
- 所有对象字段名必须使用英文双引号；所有字符串值必须使用英文双引号；禁止尾随逗号。
- 如果内容过长，优先压缩 detailed_analysis、reasoning_brief、common_mistakes 和 DU/SU 的文字长度；不得为了缩短输出而合并独立采分点。只有在题面本身没有独立作答要素时，才允许减少scoring_units数量。
- 输出前在心中检查：`json.loads()`可解析、score_share合计=1.0、knowledge_links share合计=1.0、competency_weights合计=1.0。

## JSON Schema 说明

### 顶层字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| scoring_units | array[SEU] | 是 | 采分证据单元列表，至少1个 |
| diagnostic_units | array[DU] | 否 | 诊断干扰单元列表 |
| stimulus_units | array[SU] | 否 | 情境/材料单元列表 |
| answer | string | 是 | 标准答案（选择题写选项如"C"，非选择题写要点） |
| total_score | integer | 是 | 本题满分分值（必填，从题目中的分值标注提取，如"(6分)"；无标注时选择题默认2分） |
| detailed_analysis | string | 是 | 核心分析（100字以内，只写要点） |
| difficulty | string | 是 | "简单"/"中等"/"困难" |
| knowledge_points | array[string] | 是 | 3-5个核心知识点。必须使用课程标准中的内容知识术语（优先使用教材章节标题级概念）。禁止写能力/方法描述（如"综合分析能力""辩证思维"），只写知识内容（如"价值规律""人民代表大会制度""矛盾的普遍性与特殊性""文化自信"）。同一概念用统一名称 |
| common_mistakes | array[string] | 是 | 2-3个核心易错点，每个15字以内 |

### SEU（采分证据单元）字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| seu_id | string | - | 唯一标识，如"seu_1" |
| label | string | - | 人可读标签，如"判断价值规律的作用" |
| score_share | float | 0.0-1.0 | 该SEU占本题总分的比例 |
| allocation_source | string | "explicit"/"inferred" | 该SEU的分值分配依据。explicit=该SEU自身有独立的分值标注（如大题小问标"(3分)"）；inferred=SEU分值是推断的。注意：选择题"每小题2分"是题目级标注，SEU内部的分值切分仍是inferred |
| allocation_confidence | float | 0.0-1.0 | 分值分配的置信度 |
| knowledge_links | array[KL] | - | 涉及的知识点及占比 |
| bloom_level | integer | 1-6 | Bloom层次（1识记：直接回忆概念/原理名称，如"什么是人民代表大会制度" 2理解：用自己的话解释原理或判断对错 3应用：将原理用于新情境 4分析：综合多原理找因果、辩证分析 5评价：论证判断方案/政策的合理性 6创造：开放探究、自主设计论证路径） |
| competency_weights | object | - | 四维素养权重（政治认同/科学精神/法治意识/公共参与，总和=1.0） |
| difficulty_estimate | float | 0.0-10.0 | 该SEU的难度估计，按真实认知负荷（见下方"difficulty_estimate 评分标尺"） |
| reasoning_brief | string | - | 解题思路要点（40字以内） |

### KL（知识点链接）字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| knowledge_point | string | - | 知识点名称。只填教材标准知识点名词（<=12字，如"价值规律""人民代表大会制度""矛盾的普遍性与特殊性""中国共产党的领导"）；禁止填能力/方法词（辩证分析/综合运用/理性思维）、答案推理整句、含冒号或比例数字的句子、题干情境描述 |
| share | float | 0.0-1.0 | 在SEU中的占比（同一SEU内所有share加总=1.0） |

### competency_weights 字段（四维素养权重）

每个SEU必须输出四维权重，总和=1.0：
```json
{"政治认同": 0.2, "科学精神": 0.6, "法治意识": 0.1, "公共参与": 0.1}
```

**判断标准（对比性边界，先分清归属再赋权）**：
- **政治认同**（价值认同层）：涉及拥护党的领导、认同中国特色社会主义道路理论制度文化、践行社会主义核心价值观、认同国家方针政策。**凡是要求学生判断或论证"某一路线方针政策的正确性/优越性"，或辨别"党/国家/人民利益一致性"的 SEU，归政治认同**，不要归科学精神。例：阐述坚持党的领导的必要性、认同中国特色社会主义制度优势。
- **科学精神**（理性分析层）：坚持马克思主义科学世界观方法论，运用经济原理、政治原理、哲学原理进行理性分析论证，辩证地看待问题。**凡是要求学生"运用××知识分析说明"，调用原理+联系材料进行因果论证、辩证分析的 SEU，归科学精神**——这是主观题分析说明类的核心维度。例：运用价值规律分析价格变化原因，运用矛盾原理分析政策优缺点。
- **法治意识**（规则规范层）：尊法学法守法用法，明确权利与义务界限，依法参与社会公共事务，依法办事。**凡是涉及法律条文适用、公民权利义务判断、依法治国原则、政府职能与权限边界的 SEU，归法治意识**。例：判断公民权利的正确行使方式，识别依法行政与违法行政。
- **公共参与**（实践行动层）：有序参与公共事务，行使政治权利，履行社会责任，积极建言献策。**凡是要求学生"结合材料提出建议/措施"，或分析公民/组织参与社会治理行为的 SEU，归公共参与**。例：提出促进消费的合理建议，分析公民依法有序参与政治的途径。

**反集中提醒**：思政题中科学精神（原理运用分析）客观偏多是合理的，尤其主观题几乎每个采分要点都以科学精神为核心，无需机械均分，但**不要把所有"涉及党和政府"的题都归政治认同**。判断顺序——先问"这一步主要靠的是什么？"调用原理理性分析→科学精神；道路制度方针认同→政治认同；法律权利义务→法治意识；参与实践建言献策→公共参与。多数题目至少涉及2个维度。

**主观大题尤其注意（逐个 SEU 判核心任务，勿一律压政治认同）**：主观题往往含大量"运用原理分析材料"的 SEU——这些 SEU 的 competency_weights 必须以科学精神为主；含"提出建议措施、公民参与途径"的 SEU 以公共参与为主；含"判断权利义务边界、依法办事"的 SEU 以法治意识为主；只有纯价值认同、道路认同判断的 SEU 才以政治认同为主。按各 SEU 真实核心任务赋权即可，切勿把分析论证型 SEU 也默认成政治认同。

### difficulty_estimate 字段（采分点难度估计，按真实认知负荷）

每个SEU必须给 0.0-10.0 的难度估计。**按"解出该采分点所需的真实认知负荷"评，不是按题型、选项位置或表面长度。**

**区间锚点**：
- ≤3.5 简单：直接回忆单一原理/概念，单步判断（如"价值规律的基本内容是什么""判断人民代表大会的职权"）
- 3.6-5.5 中等偏易：单一原理应用，或两步推理（如根据单一哲学原理判断材料中的做法是否正确）
- 5.6-7.5 中等偏难：多原理综合调用，或3-4步论证链（如综合运用经济、政治多模块原理分析材料）
- >7.5 困难：多原理交叉、辩证分析、开放性论证（如辨析题的双向论证，综合调用哲学多原理对现象做全面辩证分析）

**关键口径（防止综合题被拆散低估）**：
- 需要"读材料→调原理→结合分析"链式论证，或整合多个模块原理才能判定的采分点，即使来自选择题选项，也应给 7+。
- 不要因为题目被拆成多个采分点，就把每个都按局部简单判断给低分——若该采分点的正确作答依赖整合全题材料与多条原理，其难度应体现这种整合负荷。
- 难度估计应与 bloom_level 协调：bloom≥4（分析/评价）的采分点通常难度≥6，bloom≥5 通常≥7；纯识记/理解（bloom≤2）通常≤4。

### DU（诊断干扰单元）字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| du_id | string | - | 唯一标识，如"du_A" |
| option_or_trap | string | - | 选择题写选项如"A"，非选择题写"trap_1" |
| distractor_type | string | misconception/partial_truth/calculation_trap/reading_trap | 干扰类型 |
| misconception | string | - | 学生持有的错误认知 |
| trap_strength | integer | 1-3 | 干扰强度（1弱 2中 3强） |
| knowledge_boundary | string | - | 知识边界说明 |
| if_selected_means | array[string] | - | 如果学生选了该项/犯了该错，说明什么 |

### SU（情境/材料单元）字段

| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| su_id | string | - | 唯一标识，如"su_1" |
| stimulus_type | string | text/chart/table/diagram/multi | 情境类型 |
| complexity | integer | 1-3 | 1纯文字 2简单图表/数据 3复杂图表/多材料需推理 |
| is_core | boolean | - | 是否为解题核心依据 |
| description | string | - | 情境说明（30字以内） |

## 关键规则

### 分值守恒
所有scoring_units的score_share之和**必须等于1.0**。
每个SEU内knowledge_links的share之和也**必须等于1.0**。

### 选择题规则
- **强制逐项分析**：必须先逐个分析 A/B/C/D 四个选项各自考查的知识点，每个考查独立知识点的选项各自成为一个 SEU。选择题 SEU 数量**通常为 2-4 个**，禁止默认只给 1-2 个 SEU。
- **合并是例外，不是默认**：仅当多个选项考查的是**完全相同**的知识点（同一概念、同一原理）时，才允许合并为 1 个 SEU；只要考查的知识点有实质差异（即使同属一个模块），就必须拆成不同 SEU。
- **唯一允许少于 2 个 SEU 的情形**：简单识记类选择题，且全部四个选项考查的是同一个核心概念的不同表述（如"下列关于人民代表大会制度的叙述"四项全围绕同一制度概念）——此时可只输出 1 个 SEU，并在 reasoning_brief 中说明"四选项考查同一核心概念，合并为单 SEU"。除此之外不得只给 1 个 SEU。
- **DU只记录有高教学价值的典型误区**（trap_strength≥2），不要机械地为每个错误选项生成DU。如果某选项的排除难度很低（一看就知道错），不需要为它生成DU
- **DU 数量反锚定**：DU 数 = 题目中真实存在的高教学价值干扰项数量，由题目实际决定，**严禁默认恒为 3 个**。有几个值得诊断的典型误区就写几个；只有 1 个强干扰项就只写 1 个 DU，没有就写空数组 []。
- 如果题目有图表/材料 -> stimulus_units

### 非选择题规则
- 每个小问（子题）-> 1个或多个scoring_units；如果同一小问内有多个答案要点、多个"①/②"任务、多个需要分别给分的采分点，必须拆成多个SEU。
- SEU的最小粒度是"一个独立作答要素"，不是"小问编号"。主观题中每个"原理+材料结合分析"的答案要点（采分点）各成一个SEU。例如一道"运用矛盾原理分析"的题有三个采分要点，则拆为三个SEU。
- 对含有4个及以上采分要点的非选择题，scoring_units数量通常不得少于采分要点数量的60%，且不得少于4个；除非这些要点共同构成同一不可分割的论证，并在reasoning_brief中说明。
- 共享的背景材料/图表 -> stimulus_units
- DU只记录典型的有诊断价值的错误路径（0-3个），不要每题都凑3个。如果你输出了3个DU，请确认每个都有独立的教学诊断价值，否则删除最弱的那个。
  简单识记选择题（如直接判断原理对错）：0-1个DU即可，没有有价值的误区就输出空数组 []。
  DU数量不是越多越好，trap_strength=1的DU如果缺乏教学诊断价值就不要输出
- trap_strength=1（弱干扰）也是合法值——排除难度低但仍有一定误导的选项可标记为1
- 简单识记题可以只有0-1个DU。不是每道题都需要DU

### 分值提取
从分节信息提取单题分值：
- "每题X分"或"每小题X分" -> total_score=X
- "共X分"且明确题目范围 -> total_score=X/题目数
- 无法推断时默认：单选2分，多选4分，填空每空1-2分，大题12-14分
