**四大核心素养定义（对比性边界 — 先分清归属，再赋权重）**：

> 关键判断：四个素养常常"看起来都沾边"，必须用下面的**对比性边界**把每一步思维归到最恰当的一类，避免把所有需要思考的题都堆给科学思维。

1. **生命观念**（认识生命现象及其规律）
   - 结构与功能观：结构与功能相适应（如细胞膜结构与功能）
   - 进化与适应观：生物进化及环境适应（如自然选择、物种形成）
   - 稳态与平衡观：生命系统维持稳定（如血糖调节、生态平衡）
   - 物质与能量观：物质能量变化（如ATP、光合作用、能量流动）
   - **边界（重要）**：凡是**基于生物学概念本身**做出的因果判断、机理解释，归生命观念，**不要归科学思维**。
   - 正面案例：题目问"动作电位为何会在神经纤维上单向传导""植物缺镁为何叶片发黄"——这是直接调用生物概念解释因果 → **生命观念**（而非科学思维）。
   - 反例（不属于本类）：纯粹的遗传比例计算、读图求斜率，这些不依赖具体生物概念的定量推理 → 归科学思维。

2. **科学思维**（运用科学思维方法认识规律）
   - 归纳与概括：从具体归纳一般（如总结酶的特性）
   - 演绎与推理：从规律推导结论（如系谱图分析、基因型推导）
   - 模型与建模：构建模型解释现象（如DNA模型、种群增长模型）
   - 批判性思维：质疑、分析、评价（如评价实验合理性）
   - 创新性思维：提出新方法（如改进实验设计）
   - **边界（重要）**：仅当解题主要依赖**独立于具体生物概念**的通用思维方法（定量计算、逻辑演绎、数学建模、读图取数、批判评价）时才归此类。
   - 正面案例：系谱图推导致病基因显隐与位置、按分离/自由组合定律算后代比例、由实验数据曲线求最适温度 → **科学思维**。
   - 反例（不属于本类）：用"内环境稳态"概念解释为什么剧烈运动后血浆pH基本不变——这是概念性因果判断 → 归生命观念，不要因为"需要推理"就划给科学思维。

3. **科学探究**（发现问题并通过探究解决）
   - 提出问题 / 作出假设 / 制订计划（实验设计、方案制定）/ 实施探究（实验操作）/ 得出结论（数据分析）/ 表达交流
   - **边界**：题目要求设计实验、设置对照、控制变量、分析实验数据/曲线/表格、依据实验结果推断或下结论时归此类。
   - **重要（针对实验大题/数据分析题）**：判断依据是**学生的主要任务**而非题面概念多少。即使题目富含生物学概念（光合、代谢、遗传机理等），只要学生的核心任务是**分析实验/解读数据/设计或评价方案/据结果推断**，就应以**科学探究为 primary**——概念只是探究的材料，不要因为概念多就压成生命观念。
   - 正面案例：给出多组实验数据/曲线要求分析得结论、依据消化道内容物数据判断食性、设计杂交/育种方案 → **科学探究**。
   - 反例（不属于本类）：只是"运用某实验结论解释现象"、学生主要任务是调用概念解释因果而不涉及探究环节的，按解释内容归生命观念或社会责任。

4. **社会责任**（运用知识参与社会决策）
   - 关注健康（疾病、营养、AIDS、癌症）/ 关注环境（生态、污染、可持续发展）/ 理性决策（转基因、疫苗接种）/ 科学伦理（克隆、基因编辑）
   - **边界（重要）**：当题目置于**真实应用情境**（健康/疾病、环保/生态、农业生产、伦理决策）并要求据此判断或决策时，应计入社会责任，**不要一律压成科学思维或生命观念**。
   - 正面案例：题目以"合理使用抗生素避免耐药菌""退耕还林恢复生态"为情境要求作出判断 → **社会责任**（通常与生命观念并列）。
   - **可作 primary**：当题目核心落点是基于生物学知识对健康/疾病、环境/生态、生产/伦理作出**判断或决策**（如评估某疗法/用药/防治措施、生态治理或育种方案的利弊得失）时，社会责任可作为 primary，不要一律让位给生命观念。
   - 反例（不属于本类）：仅把健康/环境作为背景文字而真正考的是概念或计算，则归生命观念/科学思维，社会责任权重可低或为0。

**权重分配规则**：
- 单一素养题：主要素养权重 1.0
- 双素养题：主要0.6-0.7，次要0.3-0.4（总和=1.0）
- 三素养题：主要0.5，次要0.3，第三0.2（总和=1.0）
- 四素养题（综合性极强）：0.4, 0.3, 0.2, 0.1（总和=1.0）
- **严禁平均赋权（0.25/0.25/0.25/0.25，或多个并列最高值）**：四素养即使都涉及，也必须依据"核心考查任务"分出明确主次，最高权重只能落在一个素养上。综合大题尤其如此——你在"分析说明"里点明谁是"核心任务/核心考查/核心落点"，谁就必须拿最高权重（≥0.4）。平均赋权＝回避判断，不允许。

**primary_competency判断**（按对比性边界归类，避免过度集中到科学思维）：
- 取权重最高的素养为 primary（权重必须分出唯一最高，不得并列）
- **primary 必须等于你在分析说明里点明的"核心任务/核心考查/核心落点"所对应的素养**：若你写了"核心任务是分析数据/实验探究"，primary 必须是科学探究；写了"核心是基于情境作风险评估/决策"，primary 必须是社会责任——绝不允许嘴上说核心是探究/责任、却把 primary 和最高权重判给生命观念。
- 概念理解题 / 基于生物概念的机理因果题 → 生命观念
- 通用方法的推理分析题（系谱图逻辑、定量计算、读图取数）→ 科学思维
- 实验设计 / 控制变量 / 分析实验数据曲线表格 / 据数据下结论题 → 科学探究
- 真实应用情境（健康、环境、生产、伦理）需据此判断或决策的题 → 社会责任
- **针对实验大题/综合题的自检（重要）**：先问"学生的主要任务是什么"——
  · 主要在**分析实验 / 解读数据 / 设计或评价方案 / 据结果推断** → primary = 科学探究（哪怕题面概念丰富）；
  · 主要在**调用生物概念解释机理因果** → primary = 生命观念；
  · 主要在**基于健康/生态/生产情境作判断决策** → primary = 社会责任。
  不要默认把概念丰富的实验大题都判成生命观念。
- **自检**：若你打算把 primary 定为科学思维，先确认这一步**不是**靠生物概念本身完成的因果判断（那种应归生命观念）。

**competency_level**（素养要求层次）：
- "低"：识记、理解基础概念
- "中"：应用概念、简单推理
- "高"：复杂推理、综合分析、创新设计
